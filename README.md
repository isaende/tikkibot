## 🐞 Tikki Bot – RoboCup

📌 **Sobre o projeto**

Este site foi desenvolvido para apresentar a Tikki, nosso robô-joaninha criado para a competição RoboCup da faculdade.
O objetivo é mostrar de forma interativa o conceito do robô, sua arma, hardware, galeria de imagens, vídeos de testes e a equipe responsável.

##
🎨 **Layout**

O site conta com:
- Página inicial (Hero Section): apresentação com imagem e chamada principal.
- Sobre: explicação do projeto e da inspiração no design de joaninha.
- Arma: detalhes sobre o sistema de ataque (asas com alfinetes).
- Hardware: informações sobre materiais e eletrônica.
- Galeria: imagens do robô em diferentes ângulos.
- Vídeos: demonstrações do Tikki em ação.
- Equipe: apresentação dos integrantes.
- Rodapé: links de contato e redes sociais.
##

🛠️ **Tecnologias utilizadas**
- HTML5
- CSS3 (com variáveis, responsividade e animações leves)
- GitHub Pages (para deploy)
